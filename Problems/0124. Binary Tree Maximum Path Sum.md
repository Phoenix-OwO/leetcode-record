# 124. Binary Tree Maximum Path Sum

[Link](https://leetcode.com/problems/binary-tree-maximum-path-sum/)

**Topics**: Binary Tree, DP, Tree

## Notes

其實不難 但更新答案的時候要小心 然後學會了nonlocal __  這個用法

260925 更新C++ 寫法
途中更新ans 的話只要回傳目前最這個點以下的最大的path 就好
（要記得不可以左右都選，所以我們選一）
題外話：要放在max 裡面的話如果有大於兩個元素可以這樣包 {0, leftSum, rightSum}

```C++
class Solution {
private:
    int ans = INT_MIN;
public:
    int maxPathSum(TreeNode* root) {
        int currSum;
        currSum = dfs(root);
        return max(currSum, ans);
    }
    int dfs(TreeNode* node) {
        int leftSum = 0, rightSum = 0;
        if (node->left) 
            leftSum = dfs(node->left);
        if (node->right)
            rightSum = dfs(node->right);
        ans = max(ans, node->val + max(0, leftSum) + max(0, rightSum));
        return node->val + max(0, max(leftSum, rightSum));
    }
};
```
