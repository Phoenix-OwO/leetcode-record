覺得這題用 C++ 寫有點麻煩，所以滾回去自己的python 舒適圈。
基本上就是從1 ~n 逐一檢查每一個數字帶進去有沒有符合，我的check 另外寫，因為我覺得有點麻煩。
check 的邏輯就是：
1. 檢查他是否符合是兩段遞增，且頭尾可以相接，或是他是否本身就遞增，
2. 因為他要整條被排成遞增，所以現在檢查的區段的每個數字都必須大於前面出現的最大值。

```python
class Solution:
    def sortableIntegers(self, nums: list[int]) -> int:
        def check(i, j):
            check = False
            if nums[i] < preMax[i]:
                return False
            for k in range(i + 1, j + 1):
                if nums[k] < nums[k - 1]:
                    if check == False:
                        check = True
                    else:
                        return False 
                if nums[k] < preMax[i]:
                    return False
            if nums[j] > nums[i] and check == True:
                return False
            return True

        ans = 0
        n = len(nums)
        preMax = [0] * (n + 1)
        for i, x in enumerate(nums):
            preMax[i + 1] = max(preMax[i], x)

        for k in range(1, n + 1):
            if n % k == 0:
                curr = True
                for j in range(0, n, k):
                    curr = curr and check(j, j + k - 1)
                    if curr == False:
                        break
                if curr == True:
                    ans += k
        return ans

```
