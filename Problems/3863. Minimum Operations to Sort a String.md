# 3863. Minimum Operations to Sort a String

[Link](https://leetcode.com/problems/minimum-operations-to-sort-a-string/description/)

**Topics**: Greedy
這一題只要求不要抓整條就好，大多數的狀況我們看一次抓1 ~ n - 1 再抓0 ~ n - 2，這樣兩次換完，但有一些狀況比較特殊，接下來討論特殊狀況：
1. ans = -1 不能換的：如前述，我們大多可以透過換兩次，但有個狀況是不可能被排好的，就是整條長度是2 而且頭尾相反的，這個狀況因為一次只能取一個，所以永遠換不好
2. ans = 1只需要一次的：頭或是尾已經排好了，就代表我們只需要排一次 （0 ~ n - 2 或是 1 ~ n - 1） 就好
3. ans = 3 要換三次的：該放在頭的放在尾、該放在尾的放在頭，就需要三次才可以把他們換到對應位置

```C++
class Solution {
public:
    int minOperations(string s) {
        int l = s.size();
        if (l == 2 and s[0] > s[1])
            return -1;
        
        unordered_map<char, int> cnt;
        string newS = s;
        for (int i = 0; i < l; i++) {
            cnt[s[i]] += 1;
        }

        sort(newS.begin(), newS.end());
        for (int i = 1; i < l; i++) {
            if (s[i] < s[i - 1]) {
                if (s[0] == newS[0] or s[l - 1] == newS[l - 1])
                    return 1;
                if (s[0] == newS[l - 1] and s[l - 1] == newS[0] and cnt[s[0]] == 1 and cnt[s[l - 1]] == 1)
                    return 3;
                return 2;
            }
        }
        return 0;
    }
};
```
