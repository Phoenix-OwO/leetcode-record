# 2597. The Number of Beautiful Subsets

[Link](https://leetcode.com/problems/the-number-of-beautiful-subsets/description/)

**Topics**: Backtracking, Combinatorics, DP, Hash Table, Math, Sorting

## Notes

有2**n的做法，也有nlogn跟n的做法，詳情請洽靈神題解，很難！dp解法：按照%k去做分組，看每組可以有幾種組合，完成之後就乘起來，最後扣掉空集合的1 就完成了！O(n)的做法還沒看懂……
