我覺得這題蠻細節的，關鍵是要看出來有兩種 pattern ，分別遞增跟遞減，雖然題目要求的是遞增，但是遞減的話我們可以翻一次，把它變成遞增
因此這邊設兩種變數分別是ans1 跟ans2 ，一種是原本遞增的，另一種是原本遞減的

對於ans1 這種類型的，是我們要把它排成遞增，一種是就直接把前面的往後推，另一種方法是先反轉、拼成遞減、轉回去。（發現到轉四次跟轉兩次是一樣的，只是浪費次數，所以我們只需要管轉0 次跟轉2 次。轉兩次這個部分我沒想到，是WA 之後才發現的。
```[1,2,3,4,0] ```這個測資。

對於ans2 這種，一定要轉一次，這樣才能轉成遞增，看是要一開始就轉還是最後再轉而已。

```C++
class Solution {
public:
    int minOperations(vector<int>& nums) {
        int n = nums.size();
        int ans1 = 0, ans2 = 0;
        for (int i = 1; i < n; i++) {
            if (nums[i] != nums[i -1] + 1) {
                if (nums[i] == 0) {
                    ans1 = i;
                }
                else {
                    ans1 = -1;
                    break;
                }
            }
        }
        for (int i = 1; i < n; i++) {
            if (nums[i] != nums[i -1] - 1) {
                if (nums[i] == n - 1) {
                    ans2 = i;
                }
                else {
                    ans2 = -1;
                    break;
                }
            }
        }
        if (ans2 != -1) {
            ans2 = min(ans2 + 1, n - ans2 + 1);
        }
        if (ans1 != -1) {
            ans1 = min(ans1, n - ans1 + 2);
        }
        if (ans1 == -1 and ans2 == -1) {
            return -1;
        }
        if (ans1 != -1 and ans2 != -1) {
            return min(ans1, ans2);
        }
        return max(ans1, ans2);
        
    }
};
```
