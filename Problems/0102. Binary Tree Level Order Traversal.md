# [**102. Binary Tree Level Order Traversal**](https://leetcode.com/problems/binary-tree-level-order-traversal/)

**Topics**: BFS, Binary Tree, Tree

## Notes

有點難以解釋笑死 自己複習 用queue

260925 更新C++部分
可以不用queue，直接把ans 宣告在外面就好
```C++
class Solution {
private:
    vector<vector<int>> ans;
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if (!root) {
            return {};
        }
        dfs(root, 0);
        return ans;
    }
    void dfs(TreeNode* node, int d) {
        if (ans.size() <= d)
            ans.push_back({});
        ans[d].push_back(node->val);
        if (node->left)
            dfs(node->left, d + 1);
        if (node->right)
            dfs(node->right, d + 1);
    }
};
```
