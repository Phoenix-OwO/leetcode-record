# 3723. Maximize Sum of Squares of Digits

[Link](https://leetcode.com/problems/maximize-sum-of-squares-of-digits/description/)

**Topics**: Greedy, Math

## Notes

貪心的選digits 如果湊不出來就回傳空字串

```C++
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        if (sum > num * 9) {
            return "";
        }
        string ans = "";
        ans += string(sum/9, '9');
        if (sum % 9 != 0) {
            ans += char('0' + sum % 9);
            num -= 1;
        }
        ans += string(num - (sum/9), '0');
        return ans;
    }
};
```
