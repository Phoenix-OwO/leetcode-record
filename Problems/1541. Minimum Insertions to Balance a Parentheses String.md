蠻直觀的一題，不過需要注意的是右括號有連續一個和連續兩個這兩種case 需要注意，如果他只有一個右括號就突然遇到左邊的話，答案就要加一。
還有一個要注意的是收尾的時候，不管有多左括號還是右括號都需要額外處理
只多一個右括號或左括號的話要補兩個。

```python
class Solution {
public:
    int minInsertions(string s) {
        int n = s.size();
        int currPair = 0;
        int ans = 0;
        int cnt = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (s[i] == ')') {
                if (cnt == 1) {
                    currPair += 1;
                    cnt = 0;
                } else {
                    cnt += 1;
                }
            } else {
                if (cnt == 1) {
                    cnt = 0;
                    ans += 1;
                } else {
                    if (currPair > 0) {
                        currPair -= 1;
                    } else {
                        ans += 2;
                    }
                }
            }
        }
        ans += currPair + (cnt + 1)/2 * 2;
        return ans;
    }
};
```
