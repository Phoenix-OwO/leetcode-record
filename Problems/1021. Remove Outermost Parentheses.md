這一題只要拆最外面的，所以可以用stack 是否為空來判斷，如果pop左邊發現是空的，代表這個是最外層，此時這個右括號也不能放

```C++
class Solution {
public:
    string removeOuterParentheses(string s) {
        int n = s.size();
        stack<int> st;
        string ans;

        for (int i = 0; i < n; i++) {
            if (s[i] == '(') {
                if (st.size() > 0)
                    ans.push_back('(');
                st.push('(');
            } else {
                st.pop();
                if (st.size() > 0)
                    ans.push_back(')');
            }
        }
        return ans;
    }
};
```
