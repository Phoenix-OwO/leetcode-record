這題想很久，看了靈神的解法才發現原來可以直接看他應該會被乘2 幾次，亦即他對答案的貢獻為多少。
（透過計算他的深度 也就是幾個左括號 就知道他應該要被* 幾次 聰明）

```C++
class Solution {
public:
    int scoreOfParentheses(string s) {
        int score = 0;
        int d = 0;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') {
                d += 1;
            } else {
                d -= 1;
                if (s[i - 1] == '(')
                    score += 1 << d;
            }
        }
        return score;
    }
};

```
