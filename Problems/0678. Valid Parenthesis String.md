這題整體來說不難，但如果想要one pass 的話就要花點時間想一下
關鍵：用變數紀錄當前最多跟最少可以有幾個左括號，當遇到右括號就扣掉，如果發現扣完<0 就代表右邊太多了。
至於遇到星號就可以把上下限都拉大一點。
最後檢查如果minLeft 不是0 代表有太多左括號。

```python
class Solution {
public:
    bool checkValidString(string s) {
        int maxL = 0, minL = 0;
        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') {
                maxL += 1;
                minL += 1;
            } else if (s[i] == '*') {
                maxL += 1;
                minL -= 1;
            } else {
                maxL -= 1;
                minL -= 1;
                if (maxL < 0) {
                    return false ;
                }
            }
            minL = max(0, minL);
        }
        return minL == 0;
    }
};
```
