# 3644. Maximum K to Sort a Permutation

[Link](https://leetcode.com/problems/maximum-k-to-sort-a-permutation/description/)

**Topics**: Bit Manipulation

## Notes

把所有需要換的數字&起來就結束
（中途思考）
Q: 為什麼是全部要換的都要AND 起來？有可能他們是1 2 兩個index 一組 4 5 6 三個index 一組這樣，這時候為1 2 這組跟 4 5 6 其實不需要跟對方換。
A:分組在這一題沒有意義，因為即使第一組的AND 出來的結果可能是 1 1 或是1 1 1 ，假設第二組AND 出來的結果是 1 0 0 1 的話，中間兩位還是不可能有1，不然第二組就不能換了，所以分開討論並不會減少工作，最後我們還是得找到一個讓每一組都可以換的k ，不如一開始就把全部and 起來，完美！

```C++
class Solution {
public:
    int sortPermutation(vector<int>& nums) {
        int ans = (1 << 20) - 1;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != i) {
                ans &= nums[i];
            }
        }
        if (ans == (1 << 20) - 1) {
            return 0;
        }
        return ans;
    }
};
```
