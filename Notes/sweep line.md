## 一、核心概念

掃描線是一種「事件驅動」的解題思路。

基本流程：
1. 將問題轉換為「事件」
2. 按照某個順序（通常是座標或時間）排序
3. 用一條假想的線從左到右掃描
4. 在掃描過程中動態維護當前狀態
5. 即時更新答案

本質：
將二維或區間問題，降維為「排序 + 動態維護」。

---

## 二、標準流程

### Step 1：問題分析

確認是否可以轉換為：
- 區間問題
- 時間軸問題
- 座標幾何問題
### Step 2：事件建模（Event Modeling）

將所有影響狀態變化的點轉換為「事件」。

常見事件：
- 區間開始、結束
- 矩形左右邊界
- 高度變化點

對於區間 [l, r]：
- 加入事件 (l, +1)
- 加入事件 (r, -1)

或使用結構：
(x, type, value)

### Step 3：事件排序（Sort Events）

通常依照：
- x 座標由小到大

若相同座標：
- 依問題需求決定順序（例如先處理開始再處理結束）


### Step 4：掃描與維護狀態（Sweep & Maintain）

從左到右遍歷事件：
- 若是開始事件 → 加入結構
- 若是結束事件 → 移除結構

常見維護結構：
- Max Heap
- Balanced Tree
- Ordered Set
- Difference Array


### Step 5：更新答案

在每個掃描點：
- 更新最大值
- 計算覆蓋長度
- 計算當前重疊數


### Step 6：輸出結果

回傳最終計算結果。


## 三、常見資料結構選擇

需求 → 建議結構

- 只需要計數 → 差分陣列
- 需要最大值 → Max Heap
- 需要刪除任意元素 → 平衡樹 / TreeMap
- 需要區間統計 → 線段樹

---

## 四、時間複雜度

- 事件排序：O(n log n)
- 掃描過程：O(n)
- 總複雜度：通常 O(n log n)

若使用進階結構，可能為 O(n log n)。

---

## 五、差分思想（常用於重疊計數）

將區間 [l, r] 轉換為：

```
diff[l] += 1
iff[r] -= 1
```

掃描時：

```
cur += diff[x]
```

cur 表示目前覆蓋次數。

## 七、判斷是否適合用掃描線

符合以下特徵通常可用：

- 與區間重疊有關
- 與時間軸事件有關
- 與座標變化有關
- 需要動態維護當前最大/最小值

## 八、標準掃描線模板（偽代碼）

```
events = 建立所有事件
sort(events)

initialize data_structure

for event in events:
    更新狀態
    更新答案

return answer
```
